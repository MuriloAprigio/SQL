# 📈SQL - Estudos e Prática

## Repositório dedicado ao aprendizado e aplicação de SQL.

Este repositório contém scripts SQL desenvolvidos para fins de estudo e demonstração de diferentes conceitos e funcionalidades da linguagem.

#### Métodos e Funções Exploradas:

Neste projeto, foram utilizados e explorados os seguintes recursos do SQL:

-   **MERGE:** Para combinar dados de duas tabelas, realizando operações de inserção, atualização ou exclusão com base em uma condição.
-   **Common Table Expressions (CTEs):** Criação de conjuntos de resultados temporários e nomeados para simplificar consultas complexas.
-   **INSERT:** Adição de novas linhas de dados em tabelas.
-   **UPDATE:** Modificação de dados existentes em tabelas.
-   **CAST:** Conversão explícita de um tipo de dado para outro.
-   **CASE WHEN:** Implementação de lógica condicional dentro de consultas SQL.
-   **ROW_NUMBER():** Atribuição de um número sequencial a cada linha dentro de uma partição de um conjunto de resultados.
-   **GROUP BY:** Agrupamento de linhas com base em uma ou mais colunas, frequentemente utilizado com funções de agregação.
-   **OVER():** Cláusula que define uma janela de linhas dentro de um conjunto de resultados para realizar cálculos sem agrupar as linhas em um único resumo.
-   **PARTITION BY:** Subcláusula da função `OVER()` que divide o conjunto de resultados em partições, sobre as quais a função será aplicada.

Sinta-se à vontade para explorar os scripts e utilizá-los como referência para seus próprios estudos!
